conversion rejects outside int32 before any cast or index. Negative raw indices

single-motion path does. Native current-model pose uses this explicit runtime
entry. Clock wrapping/reflection, frame selection, rate and completion math are
unchanged. Generic blend/interpolated runtime domains remain a future source
consumer contract; this entry does not silently broaden those public APIs.

below clip count, before uint32 conversions. Their rejection preserves the whole
accepted pose and permits corrected same-owner retry. Existing strict sampler
negative/end/nonfinite tests are retained, not deleted to obtain a pass.

negative nearest/even tie, int32 lower endpoint, beyond-clip root-frame selection,
