# M22 slice 06A3B2: exact lit Vulkan translation from original source state

## Source boundary and reached behavior

The original `DX8Wrapper` and `VertexMaterialClass` issue material, shader, transform, fog, texture, ambient and four selected light slots. `OriginalGpuEdge` translates their immutable source snapshot to three exact normal-bearing FVF shader variants (XYZN, XYZN+UV1/retail 274, XYZN+UV2) and bounded std140 light/material uniforms; original TGA `TextureClass` supplies real authored fixture pixels. Original selected world/view matrices feed inverse-transpose normal conversion, with the original normalization/local-viewer/specular switches. The vertex shader performs fixed-function-style **per-vertex** ambient, diffuse, emissive, point range/attenuation and material-powered specular; fragment stage applies original 0/1/2-stage combiners, additive specular before fog, original alpha and blend. Absent COLOR1/COLOR2 attributes on these original normal-bearing FVF layouts fall back to source material, not invented vertex color. No category/polygon pass or source mesh decision was replaced.

Owned `LightEnvironmentClass` and source methods produced stable validation-enabled Vulkan RGBA readback across two device generations: ambient RGB 8:20:38; directional 105:133:156; point 80:63:60; four lights 105:102:117; nonuniform-world unnormalized/normalized red 90:99; specular off/on red 94:143; lit normal+UV1/UV2 stage red 98:226; fog red 177; lit alpha-blend red 40. Assertions independently derive expected values from original packed ambient, material/light terms, range, original texture bytes and fixed-function equations. A narrow point-light triangle accounts for original **per-vertex Gouraud** interpolation, rather than pretending a fragment-center attenuation applies to each vertex. `VK_LAYER_KHRONOS_validation` reports zero Validation Error/VUID. The read-only retail FVF aggregate remains 274 normal+UV1, three occurrences; this is **not** a retail scene draw or category-issued lit acceptance.

## Negative and lifecycle controls

Source range clipping removes point ambient and diffuse beyond range; invalid zero attenuation, invalid light slots/type and normal-free lit FVF reject. A missing original environment and unsupported lit FVF reject without replacing a prepared prior pipeline. Injected Recording shader creation and uniform upload fail without leaked handles; original source revision/retry validates a new lit descriptor. Normal-only FVF with required UV rejects, while valid 0/1/2-stage source FVF and original TextureClass owners work across two fresh Vulkan device generations. The original null-environment branch retains previously selected global lights; an earlier category negative based on assuming null cleared them was removed, while dedicated original category lit acceptance remains 06A3C. 06B/C, GameClient 07, retail 08 and final validation/visual 09 are still mandatory.
