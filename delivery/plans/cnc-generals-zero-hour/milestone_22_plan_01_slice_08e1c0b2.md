# M22 08E1C0B2: generated map-preview and start-marker helper closure

After C0B1, C0B2 is dependency-split. **C0B2A** proves the actual source
map-preview file/copy/mapped-image resource route with generated data. **C0B2B**
then consumes that route from the source start-marker helpers with live
project-owned source GUI windows, GameInfo, and GameText. The resource copy can
fail/retry and release independently, while the GUI consumer cannot be proven
without it. Neither slice composes the multiplayer load-screen owner or claims
retail maps, pixels, media, or network service behavior.

## Aggregate transaction

This final C0B2 aggregate adds no production path. Its one executable witness
must run the accepted C0B2A preview provider before the accepted C0B2B label
and placement helpers, and require each to report its independently proven
two-generation, zero-resource result. Missing witnesses or a changed result
are deterministic failures. The component slices retain their direct
failure/retry, malformed-input, removal, and teardown controls; this aggregate
does not duplicate or relax them.

The witness is generated-data only and does not access retail content. It
proves resource-to-GUI provider ordering, not a retail WND layout, pixel,
audio, media, multiplayer service, or final load-screen-owner claim. Required
validation is focused GCC/Clang coupling, source identity/provider ledger
checks, the six configured non-GPU/non-LAN suites, strict host LSan for both
compilers, proportional physical Vulkan, and serial LAN in every configuration.

Commit boundary: one test-only aggregate, its CMake registration, ledger and
plan/evidence updates in `delivery: M22 08E1C0B2 preview marker aggregate`.
