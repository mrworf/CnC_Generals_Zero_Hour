# M22 plan 01 slice 07FF: integrated generated map scene recording gate

## Outcome and dependency

Requires 07FA through 07FE. Exercise one bounded generated map scene through
the original production-order display, tactical view, terrain visual and
source object graph, combining the accepted terrain, shroud, track, water,
shadow and effect routes in a balanced Recording frame. This is the full 07
semantic integration gate before private retail input is permitted.

## Acceptance

Require source-identified ordered commands from every enabled family, plus
feature absence controls, missing/malformed generated asset rejection,
injected failure at each producer boundary, reset/re-entry and zero source/
device ownership. It must prove that no remaining map-loaded guard is
reachable in the generated full-feature profile. It makes no retail or
physical-pixel claim.

## Delivery refinement

Implement this as one dedicated `ZH_M22_FULL_FEATURE_PROFILE` probe, not a
sequence of existing profile invocations.  The engine entry point will retain
the source drawable's original scene/asset aliases, temporarily unpublish only
the static W3D aliases, then transfer that same source render object into the
live generated-map display built by the probe.  The probe owns the generated
map packet, tracks, type-0 water, source decal caster, particle provider and
one smudge.  It records their order in one frame and exercises malformed or
missing map, duplicate/detached caster, disabled sibling, producer create /
upload / draw failures, retry, reset and two-generation teardown.
