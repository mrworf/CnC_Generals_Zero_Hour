# Arch x86-64 target update

Product ID: `cnc-generals-zero-hour`

## Goal

Update the native Linux port authority to remove the obsolete ARM64 development target, make the current Arch Linux x86-64 host the mandatory playable target, retain Ubuntu and Fedora as clean-build portability targets, and record the verified retail-data and Vulkan prerequisite state.

## Approved decisions

- Support x86-64 only.
- Use Arch Linux x86-64 as the primary development and playable acceptance environment.
- Retain Ubuntu 26.04 and Fedora 44 for clean-build CI portability checks.
- Use `original_game_symlink` as the local read-only retail source, with Zero Hour at its root, base Generals under `ZH_Generals`, and English as the selected locale.
- Treat the RTX 4070 and NVIDIA 610.57.04 Vulkan implementation as available; require the missing Khronos validation layer before M14.
- Keep Windows 1.04 save/replay compatibility optional because no suitable fixtures were found.

## Completion

The port plan contains no ARM64 requirements or claims, identifies Arch as the playable target, keeps Ubuntu/Fedora clean-build coverage, accurately records the GPU and fixture state, and prevents accidental tracking of the local retail symlink.
