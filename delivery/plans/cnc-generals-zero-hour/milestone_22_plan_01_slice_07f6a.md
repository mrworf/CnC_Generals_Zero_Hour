# M22 plan 01 slice 07F6A: source packed terrain texture format

## Goal and observable outcome

Requires accepted 07F5. The renderer contract and `OriginalGpuEdge` can create,
upload, retain and destroy a bounded sampled texture corresponding exactly to
source `WW3D_FORMAT_A1R5G5B5`, using the public SDL and bgfx packed 16-bit
formats. Recording and host Vulkan controls witness the same descriptor,
two-byte texel layout and failure behavior without constructing a terrain atlas.

## Dependency finding and scope

Native `TerrainTextureClass` unconditionally constructs its base atlas as
`WW3D_FORMAT_A1R5G5B5`. The accepted edge maps BGRA8 and BC formats but rejects
this source format, while the pinned public APIs expose exact equivalents:
SDL `B5G5R5A1_UNORM` and bgfx `BGR5A1`. Atlas ownership cannot proceed without
this translation.

Add one sampled-color format to the renderer contract, validators, Recording,
SDL and bgfx mappings and source-format translation. Support only ordinary 2D
sampled creation/upload and existing destruction/re-entry. Do not add render
target, storage, depth, readback conversion, atlas packing, `TerrainTextureClass`,
terrain material, draw or pixel claims. Those remain dependency-ordered 07F
children.

## Entry, state, errors and surfaces

The direct probe asks `OriginalGpuEdge` to create a small source
`A1R5G5B5` texture, uploads deterministic packed texels and releases it before
edge teardown. Recording exposes exact format, pitch, byte count and resource
retirement; public SDL and bgfx devices shader-sample the four channel/alpha
bit patterns on the host Vulkan backend.

Zero extents, unsupported render-target combinations, bad pitch/byte
count, stale handles, injected creation/upload failure and source formats other
than the explicit mapping continue to fail before publication. Re-entry uses a
second edge/device generation. Authorization is not applicable: this is a
local renderer resource contract with generated bytes and no external input.

Expected surfaces are the renderer texture-format contract and three device
mappings/validators, canonical `OriginalGpuEdge` translation, direct focused
tests, dependency ledger, plan/index and evidence. Retail inputs and retail
symlink content remain untouched.

## Tests and acceptance

Positive tests cover source-format identity, two-byte texels, descriptor and
upload preservation, destroy and two-generation re-entry on Recording plus
physical SDL/bgfx Vulkan shader samples. Negative tests cover malformed
uploads, invalid usage/extents, stale handles, injected failures and an
unmapped source format.

Run focused GCC/Clang and direct physical repetitions, identity/provider and
ledger controls, exact five non-LAN suites with leak-capable GCC/Clang
ASan+UBSan/LSan, and the established LAN split. No terrain draw/pixel gate
applies because this prerequisite only closes texture resource transport.

## Commit boundary

One commit: `delivery: M22 slice 07F6A map packed terrain texture format`.

## Result

Complete. The new public format is appended without renumbering existing ABI
values. Recording and the original edge preserve exact packed bytes and close
injected failure/retry paths. SDL and bgfx both reject render-target use and
sample opaque red/green/blue plus alpha-clear correctly across repeated host
Vulkan generations. Terrain atlas ownership, material submission and terrain
pixels remain pending 07F6B and later children.
